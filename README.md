# Rock Paper Scissors
A web based version of rock paper scissors coded with HTML, CSS, and JavaScript.\
Developed as apart of the curriculum for [The Odin Project](https://theodinproject.com)  

## Known Bugs:
- It is possible for both btn-containers to appear with the winning CSS properties.\
This does not affect gameplay and can be resolved by clicking the `Reset Game` button
